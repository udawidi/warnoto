# Quickstart and Verification

1. Jalankan aplikasi lokal.
2. Buka Stock Opname.
3. Simpan dan edit data pada akun ADMIN/Fajar serta akun pengguna biasa.
4. Pastikan tidak ada pesan blokir freeze dan perubahan tersimpan.
5. Verifikasi update realtime, `updated_at`, GI, dan Barcode.
6. Terapkan migration removal pada environment review sesuai prosedur project.
7. Jalankan typecheck/build/test relevan.
8. Pastikan tidak ada 403, error RPC freeze, atau event Realtime yang hilang.
