# Quickstart Validation: Operasional MTU KHS

1. Jalankan unit contracts MTU KHS.
2. Jalankan `npm run build`.
3. Setelah migration disetujui dan diterapkan, login TL UPT asal.
4. Edit katalog/status/lokasi internal dan cek audit setelah reload.
5. Upload serta ganti foto barang/nameplate; cek active dan history.
6. Ajukan transfer parsial ke UPT satu UIT.
7. Login ASMAN asal dan approve.
8. Login TL tujuan; cek record, qty, lokasi, foto, dan audit.
9. Ulangi request/approval yang sama; pastikan tidak ada split ganda.
10. Pastikan `mtu_khs_sheet_sync_jobs` tidak bertambah.
